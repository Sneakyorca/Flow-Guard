# FlowGuard

Autonomous QA & critical-flow monitoring — "Uptime Robot for user journeys".

Describe a user journey in plain English; FlowGuard runs it on a schedule in a headless
Playwright browser, uses an LLM to resolve each step to a real element, and when something
breaks you get a video replay, console/network diagnostics, an alert, and a shareable link.

Status: scaffolding in progress.
